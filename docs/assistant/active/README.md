# Active work

Use this folder for work that is still evolving:

- Open design questions
- In-progress investigations
- Working summaries
- Draft implementation context

When a thread is approved, move or summarize it in `decisions/`. When it is complete but still useful as evidence, keep the durable result in `research/`.
