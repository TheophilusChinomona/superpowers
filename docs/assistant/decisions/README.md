# Decisions

Approved choices that should guide future work.

Use filenames in this form:

`YYYY-MM-DD-short-decision-name.md`

Each decision should state:

- The decision
- Why it was chosen
- Alternatives considered
- Consequences
- What would cause it to be revisited
